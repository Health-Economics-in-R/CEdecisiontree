# Insert to transition matrix

<div class="ref-description section level2">

Insert values into a transition matrix from a long array of `from`, `to`
values

Insert values into a cost matrix from a long array of `from`, `to`
values

Insert values into a probability matrix from a long array of `from`,
`to` values

</div>

<div class="section level2">

## Usage

<div class="sourceCode">

``` r
insert_to_transmat(dat, mat)

insert_to_costmat(dat, mat)

insert_to_probmat(dat, mat)
```

</div>

</div>

<div class="section level2">

## Arguments

-   dat:

    Long from-to-vals array. Either cost or prob.

-   mat:

    Transition matrix

</div>

<div class="section level2">

## Value

matrix

transition matrix

Probability matrix

</div>
